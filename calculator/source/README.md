# Калькулятор Telegram Stars → рубли

Актуальный макет: https://www.figma.com/design/lzicbzifnTOKF6C6VAdHS9/Zvezdach---Dev?node-id=1105-96112
Референс движения: https://bencho.dev/?c=asset-swap&theme=light

- React 19, TypeScript, Vite; оригинальные RF Dewi Condensed Black, Inter Medium и JetBrains Mono Bold.
- Курс 1,7 ₽ за звезду задаётся в `src/calculator-config.ts`.
- Ввод в обе стороны, тонкие неразрывные пробелы U+202F, плавная прокрутка отдельных цифр NumberFlow.
- Стрелка меняет поля местами; способы оплаты переключаются с плавным индикатором.
- Кнопка передаёт количество звёзд и способ оплаты в сохранённую исходную форму покупки (`?checkout=1`). Её серверная оплата не добавлялась.
- Состояние сохраняется при возвращении из покупки кнопкой браузера «назад».
- Оригинальные эффекты Figma подключены через выданный Figma WebGPU runtime. Часы переведены из миллисекунд в секунды; движение проходит вперёд и назад без сброса, большие паузы ограничены. В браузерах без HTML-in-Canvas, при reduced motion и с `?still` используется оригинальный экспорт только фонового слоя.

## Запуск и сборка

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build:v2
```

Статическая сборка — `dist-v2/`. Её можно открыть через `index.html` или разместить на статическом хостинге. Пути относительные, внешние CDN и Google Fonts не требуются.

На GitHub исходники лежат в `calculator/source/`, проверенная сборка — в `calculator/site/`. Основная сборка репозитория копирует её в `/calculator/`, сохраняя остальные блоки проекта. Чтобы обновить опубликованный калькулятор, соберите исходники и замените содержимое `calculator/site/` результатом из `dist-v2/`.

Проверка макета и адаптива — `design-qa.md`. `qa.html` и `qa-responsive.html` — локальные области сравнения, в публичную сборку не включены.
