# Способы оплаты: проверка перед публикацией

**Результат локальной проверки: пройдено.**

Макет: https://www.figma.com/design/lzicbzifnTOKF6C6VAdHS9/Zvezdach---Dev?node-id=1105-74118

Публикуемый маршрут: https://zvezdach-stars-block.vercel.app/payments.html

## Точность

Проверена область браузера 1411 × 600 с блоком 1411 × 564. Заголовок: x144/y174, 437 × 144; первая карточка x693/y64, 384 × 436. Эти размеры совпадают с Figma. Отступы 144/64, расстояние до карточек 112, шаг карточек 400, радиус карточек 24. Использованы исходные тексты, три фирменных шрифта и графика из макета. Сравнение: `evidence/payments/comparison.jpg` (Figma сверху, браузер снизу).

Шесть стикеров получены из оригинальных SVG в двойном разрешении. Исходные SVG не изменены. Это исправляет потерю обводок / масок в WebKit. Облака и стрелка кнопки остаются исходными SVG; стрелка переключателя экспортирована из оригинального SF Symbol. Захват браузера содержит JPEG-сжатие и ICC Display P3; изображения сравнения переведены в sRGB. Артефакты сжатия на бирюзовых участках относятся к захвату.

## Поведение

Проверен живой референс https://wise.com/: следующая карточка перекрывает предыдущую, предыдущая затухает на своём месте, переход transform / opacity занимает 1 с. Эта механика воспроизведена, автоматического перелистывания нет.

Проверены: следующая / предыдущая карточка; быстрые нажатия вперёд-вперёд-назад; Home / End / стрелки клавиатуры; отключение предыдущей стрелки на первой карточке и следующей на шестой; перетаскивание влево и вправо в мобильной области 390 px. Нажатия по ссылкам не начинают перетаскивание. Скрытые карточки исключаются из фокуса, изменение позиции объявляется через aria-live.

Системное уменьшение движения поддерживается CSS `prefers-reduced-motion`; системную настройку компьютера при проверке не меняли. Клавиатурное перемещение выполняется без анимации.

## Ссылки и сборка

В Figma у всех карточек скопирована ссылка `/telegram-stars/sbp`. Для остальных карточек проставлены соответствующие маршруты из согласованной структуры сайта: `/telegram-stars/crypto`, `/telegram-stars/card`, `/telegram-stars/telegram-gift`, `/telegram-stars/rate`, `/telegram-premium`. Сами внешние страницы в рамках этой задачи не изменялись.

Проверка синтаксиса `payments.js` и статическая сборка `scripts/build.mjs` пройдены. Сборка копирует HTML, CSS, JS и все локальные ассеты. Карусель не требует сторонней библиотеки и не загружает Three.js. Основной золотой блок сохраняется на `/`.
