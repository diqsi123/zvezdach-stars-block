# Блок «Что такое Telegram Stars» — Звездач

[Открыть опубликованный сайт](https://zvezdach-stars-block.vercel.app/)

Вёрстка [блока из Figma](https://www.figma.com/design/lzicbzifnTOKF6C6VAdHS9/Zvezdach---Dev?node-id=1085-49340) с вращающимся металлическим знаком из **Subtract.svg**. Текст и кнопка — обычные HTML-элементы. Знак — настоящая трёхмерная модель, которая вращается в браузере.

## Просмотр

```sh
npm install
npm run dev
```

- `http://127.0.0.1:4173/` — готовый золотой блок.
- `http://127.0.0.1:4173/studio.html` — отдельный просмотр модели: пауза, поворот, экспорт PNG / GLB / WebM.
- `http://127.0.0.1:4173/?still&reference` — неподвижный кадр шириной 1440 px для сравнения с Figma.

В подготовленной папке и архиве уже есть необходимые локальные библиотеки. Для запуска достаточно Node.js и `npm run dev`; внешние CDN не используются.

## Файлы для вёрстки

- `index.html` — разметка блока и локальная карта импортов Three.js.
- `stars-section.css` — размеры, адаптив, состояния кнопки, фирменные шрифты.
- `stars-section.js` — подключение модели, учёт настройки уменьшенного движения, статичный запасной кадр.
- `zvezdach-coin.js` — модель, металлический материал, свет, анимация и экспорт.
- `assets/Subtract.svg` — правильный исходный знак, без изменения контура.
- `assets/fonts/` — RF Dewi Condensed Black, Inter Medium, JetBrains Mono Bold.
- `assets/figma/` — облака и фон из исходного блока. Золотой фон с сеткой подготовлен из исходного SVG в двойном разрешении для одинакового наложения цвета в разных браузерах. Текст, кнопка и модель в изображение не включены.
- `ZvezdachCoin.jsx` — необязательная обёртка модели для React.

Для переноса в проект нужны разметка секции, её CSS, оба JS-модуля и `assets/`. Зависимость — `three@0.169.0`. Пути к ресурсам задаются относительно файлов. Если сборщик уже умеет импортировать пакеты, HTML-карта импортов не нужна.

Кнопка ведёт на `https://zvezdach.com/telegram-stars`. В исходной Figma у неё нет заданного перехода; при интеграции адрес можно изменить в `href`.

## Размеры из макета

Исходный фрейм: **1440 × 766**. Золотая карточка: **1392 × 670**, отступы сверху/снизу 48 px, по бокам 24 px, радиус 63 px. Ширина содержимого — 506 px. Заголовок — RF Dewi Condensed Black 56 / 58,8 px, трекинг −2,24 px; описание — Inter Medium 16 / 24 px; кнопка — JetBrains Mono Bold 14 / 16 px, высота 56 px.

На ширине до 640 px блок адаптируется: боковые отступы 16 px, радиус 40 px, заголовок 36 / 37,8 px. Проверены ширины 390 и 320 px. Отдельного мобильного варианта у переданного фрейма нет.

На ширине до 360 px заголовок плавно уменьшается до 28–32 px, сохраняя две строки, в том числе при видимой полосе прокрутки. Высота карточки и вертикальные отступы учитывают доступную высоту экрана.

## Публикация

```sh
npm run build
```

Готовый статический сайт находится в `dist/`. Настройки Vercel заданы в `vercel.json`. При сборке необходимые части Three.js копируются в `dist/vendor/three/`, поэтому шрифтам и вращению не нужны внешние CDN. Изменения в `main` связанного репозитория публикуются через Vercel.

Если браузер не поддерживает WebGL, остаётся статичный фирменный знак. При включённом уменьшении движения знак не вращается. Анимация приостанавливается за пределами экрана и в скрытой вкладке. Возврат назад из кэша браузера сохраняет работающую модель.

## Отдельные 3D-файлы

В локальной папке и подготовленном архиве находятся готовые экспорты ниже. В GitHub хранятся исходники генератора; экспорты можно заново получить через кнопки на `studio.html` после локального запуска.

- `exports/zvezdach-metal-badge.glb` — геометрия, материалы и анимация.
- `exports/zvezdach-metal-badge.webm` — прозрачное видео, полный бесшовный цикл 41,8879 с.
- `exports/zvezdach-metal-badge.png` — фронтальный вид 1216 × 1056 с прозрачным фоном.

Поворот вокруг Y: 0,45 рад/с; один оборот — 13,9626 с. Наклон X: `sin(t × 0,6) × 0,08`; вертикальное движение: `sin(t × 0,9) × 0,05`. Полный цикл объединяет три оборота, четыре наклона и шесть вертикальных колебаний.

Свет и движение сверены с [публичным референсом](https://bencho.dev/). Материал — металл с радиальной шлифовкой. Для сохранения отражений на сайте используется готовая JS-сцена: вид GLB в других приложениях зависит от их освещения. В золотом блоке яркость модели повышена согласно обработке изображения в Figma.

Three.js и библиотека исправления длительности WebM распространяются по MIT; лицензии — в `node_modules/three/LICENSE` и `licenses/WebM-Duration-LICENSE.txt`. Результаты проверки публикации и адаптива — в `deployment-qa.md`.
